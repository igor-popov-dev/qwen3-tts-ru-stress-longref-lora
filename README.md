# Qwen3-TTS: русские ударения и длинные образцы голоса

LoRA для **Qwen3-TTS-12Hz-1.7B-Base**, дообученная Игорем Поповым на длинных
образцах речи. Адаптер продолжает обучение
[ru-stress от sknyazev](https://huggingface.co/sknyazev/qwen3-tts-12hz-1.7b-ru-stress-gguf):
модель получает знаки ударения в русском тексте и использует ваш образец голоса.

Здесь опубликованы **только LoRA и код запуска**. Записей голоса, готовых голосовых
профилей и полных весов Qwen в репозитории нет. Для озвучки нужен ваш WAV-файл
и точная расшифровка всего, что в нём произнесено.

## Требования

- Mac с **Apple Silicon: M1, M2, M3, M4 или новее**. Этот скрипт не поддерживает Intel и Rosetta.
- macOS **14 или новее**; сквозная проверка выполнена на macOS 26.7.
- Python **3.11**. При установленном [Homebrew](https://brew.sh/): `brew install python@3.11`.
- Рекомендуется **16 ГБ памяти** и **15 ГБ свободного места** для установки и первого запуска.
- Интернет для скачивания библиотек, исходного Qwen и моделей RUAccent.
  После заполнения кэша синтез выполняется локально.

Аудиозапись и текст не отправляются во внешний сервис синтеза.
При первом запуске несколько гигабайт моделей загружаются с Hugging Face.

## Установка

Откройте Терминал:

```bash
git clone https://github.com/igor-popov-dev/qwen3-tts-ru-stress-longref-lora.git
cd qwen3-tts-ru-stress-longref-lora
bash install.sh
```

Установщик создаст `.venv` для MLX-Audio и `.venv-stress` для RUAccent.
Окружения разделены из-за разных требований к Transformers.
Системный Python и его пакеты не изменяются.

## Первая озвучка своим голосом

1. Подготовьте чистую запись одного человека без музыки и других голосов.
   Для первого опыта удобно взять **10–30 секунд**. Скрипт допускает **3–60 секунд**;
   диапазон длинных образцов при дообучении — **9–60 секунд**.
2. Сохраните её в WAV или FLAC. Точно перепишите **всю** речь из записи в UTF-8-файл,
   например `reference.txt`. Не используйте пересказ.
3. Запустите, заменив пути на свои:

```bash
bash run.sh \
  --ref-audio "$HOME/Downloads/reference.wav" \
  --ref-text-file "$HOME/Downloads/reference.txt" \
  --text "Я закрыла дверь на замок и пошла домой." \
  --output outputs/first.wav
```

```bash
afplay outputs/first.wav
```

Первый запуск дольше: он скачивает модели, накладывает LoRA на исходные BF16-веса
и собирает 8-битную MLX-модель. Следующие запуски используют сохранённый результат.

Для короткой записи расшифровку можно передать прямо аргументом
`--ref-text "Точное содержимое вашей записи."`.
Для длинного текста используйте `--text-file текст.txt` вместо `--text`.
Пути с пробелами заключайте в кавычки. Готовый выходной файл не перезаписывается:
для следующей пробы укажите другое имя.

## Как работают ударения

По умолчанию RUAccent расставляет ударения автоматически. LoRA училась читать
комбинируемый знак **U+0301 после ударной гласной**: `за́мок`, `замо́к`, `звони́т`.
Знак `+` и заглавная гласная не заменяют этот формат.

Пунктуация, числа, латиница и слова, пропущенные RUAccent, сохраняются.
Ударения, которые вы уже поставили вручную, имеют приоритет.
Слова с «ё» и односложные слова дополнительно не размечаются.

Если весь текст размечен вручную, RUAccent можно пропустить:

```bash
bash run.sh \
  --ref-audio "$HOME/Downloads/reference.wav" \
  --ref-text-file "$HOME/Downloads/reference.txt" \
  --text "На двери́ висе́л замо́к." \
  --manual-stress \
  --output outputs/manual.wav
```

В ручном режиме слова без знаков остаются на усмотрение модели.
Числа, даты и сокращения для предсказуемого произношения лучше писать словами.

## Что именно дообучалось

Продолжение обучения исходной LoRA ru-stress: **одна эпоха**, **3 407 фраз**, пять
чтецов Russian LibriSpeech. Образцы одного чтеца склеивались до **9–60 секунд**.
Использовалась раскладка «текст блоком», соответствующая ICL-клонированию MLX-Audio.
Learning rate — `5e-5`, rank — `16`, alpha — `32`.
В 60 % примеров размечались все подходящие слова, в 40 % — 70 % таких слов.

Цель продолжения — работа с длинными эталонами без потери поддержки ударений.
Это экспериментальный адаптер, а не гарантия безошибочного произношения:
возможны неверные ударения, пропуски, обрывы и нестабильный тембр. Качество зависит
от записи, расшифровки и текста; улучшение для каждого нового голоса не обещается.
Публичного независимого сравнительного бенчмарка этой версии нет.

Обучающий набор и исходный обучающий конвейер здесь не распространяются;
это пакет для воспроизводимого запуска уже обученного адаптера.

## Формат и воспроизводимость

- `adapter/adapter.safetensors` — матрицы LoRA A/B, без записи или speaker embedding выбранного голоса.
- `adapter/adapter.json` — параметры адаптера.
- `adapter/manifest.json` — контрольные суммы и сведения о происхождении.
- `prepare_model.py` — слияние с исходной BF16-моделью и квантование по раскладке MLX.
- `synthesize.py` — локальная озвучка с вашим эталоном, разбиением текста и защитой от раннего EOS.
- `mark_stress.py` — автоматическая разметка в отдельном процессе.

Адаптер **не является стандартным PEFT-пакетом**: его ключи относятся к `talker.model`.
Формула слияния: `W ← BF16(FP32(W) + FP32(B) @ FP32(A) × alpha / rank)`.
Не накладывайте его поверх уже слитой ru-stress-модели: нужен чистый Base.

Версии исходных моделей закреплены:

| Компонент | Ревизия |
|---|---|
| [Qwen Base](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-Base) | `fd4b254389122332181a7c3db7f27e918eec64e3` |
| [MLX 8-bit, раскладка и токенизатор](https://huggingface.co/mlx-community/Qwen3-TTS-12Hz-1.7B-Base-8bit) | `e7dd0585652209fa0d7783659aad4e8a324de11c` |

Кэш и собранная модель лежат в `.cache/` и `models/` этого каталога.
Сборка создаёт `models/ru-stress-longref-8bit/merge.json` с контрольной суммой весов.
Эталон и результаты можно хранить в игнорируемых Git каталогах `references/` и `outputs/`.
Сид по умолчанию — `42`, изменить можно через `--seed`.
Результат — моно WAV, PCM 16 бит, 24 кГц.

```bash
.venv/bin/python verify_adapter.py
.venv/bin/python -m unittest -v test_helpers
```

## Проверка выпуска

На Mac M4 с 16 ГБ памяти скрипт собрал модель из этого адаптера:
SHA-256 весов **совпал с исходной рабочей сборкой**. Выполнена озвучка
со сторонним синтетическим образцом, получен корректный WAV 24 кГц.
Проверены сохранение текста и работа RUAccent. Подробности и границы проверки —
в [VALIDATION.md](VALIDATION.md).
